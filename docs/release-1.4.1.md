# 1.4.1 登录页修复与外观优化

## 变更

- 修复正式包免 Root 登录页白屏。WebView 始终挂载在原生容器内，首次加载和页面恢复均等待窗口挂载及有效尺寸，避免 Compose 条件挂载与网页初始化竞争。
- 登录二级页面统一标题栏、圆角卡片、按钮和文字层级，跟随系统深浅色；准备登录、验证中、成功及失败状态分别提供明确提示和操作。
- 适配系统栏、挖孔及键盘区域；输入时收起顶部提示卡，验证开始后收起键盘。状态说明可滚动，返回与重试按钮保留足够触控区域。
- 保持官方登录地址、域名限制、会话验证与保存流程不变。取餐码和快速模式无需 Root，专家模式仍需独立授权。

## 验证

- 白屏修复已由用户手动确认恢复正常。
- 67 项 JVM 单元测试通过；Release Lint 0 错误、36 项既有警告，新增登录界面无 Lint 警告。
- 已生成签名并压缩的 Release APK 与真机回归测试 APK；正式包名为 `com.jizizr.signaldock`，版本 `1.4.1`，versionCode `13`，签名证书与此前正式版一致。
- 新增真机回归覆盖首次打开、Activity 重建及再次进入的可见输入框，只读取页面布局信息，不输入账号凭据。此次 ADB 未连接，未执行该真机测试，也未将外观调整标记为已完成真机验收。

## 发布

使用独立中文提交记录白屏修复、界面优化和版本更新。推送 `v1.4.1` 后，由现有 GitHub Actions 检查 Rust 与 Android 代码、构建签名 APK，并发布 APK 和 SHA-256。Release Notes 自动包含 `v1.4.0..v1.4.1` 的所有提交标题与正文。
