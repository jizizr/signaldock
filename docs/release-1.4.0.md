# 1.4.0 审阅与验证记录

审阅范围包括 Android 服务与通知生命周期、截图与二维码管线、账号与网络协议、设置和历史记录、诊断日志、Rust 解析、资源与依赖，以及签名发版流程。

## 主要变更

- 修复识别中状态岛偶发跳过，至少展示 600 毫秒后切换；统一通知发布和会话清理，修复结果岛与二维码窗口生命周期。
- 新增小米取餐码、超级小爱快速与专家渠道。取餐码及快速模式支持小米官方网页登录和独立网络调用；专家模式仍需 Root 设备签名。
- 同一账号导入专家凭据时保留有效网页会话，不混合不同账号；缓存解密结果，仍实时检查有效期。
- 自动识别失败不再误标成功；仅在页面变化后允许一次重试，不增加后台轮询。
- 移除关闭的 Miclaw 通道、旧登录逻辑、AIDL 与无用资源；保留旧配置迁移和 ADB 测试组件名兼容。
- 小米截图直接上传 JPEG 字节，减少 Base64 转换；自定义接口响应上限为 4 MiB，总重试时间不超过 110 秒；错误正文不进入诊断日志。
- 提前显示 AI 设置，统一网页登录页面外观与重试操作；配置保存异步执行，显示有效性及保存状态。
- 登录和历史记录随生命周期刷新；历史记录使用请求开始时的渠道名称。

## 本地与真机验证

- JVM：67 项测试通过，覆盖账号隔离、有效期、配置校验、自动重试、诊断延迟求值、协议和通知策略。
- Rust：16 项测试通过，2 项需要外部凭据或本地图片的测试保持显式忽略；`cargo fmt --check` 与 Clippy 零警告通过。
- Android Lint：0 错误，36 项警告。剩余主要涉及厂商私有 API、现有后台授权用途、依赖版本和 KTX 建议。
- `assembleRelease` 成功，APK v3 签名验证通过。只覆盖安装正式包 `com.jizizr.signaldock`，版本为 1.4.0，versionCode 为 12。
- Xiaomi 24129PN74C、Android 17、HyperOS 4.0.0.19、超级小爱 8.2.62.3916：先完成 6 组无点击网络回归，全部通过：普通码 5312、前导零 0076、混合码 B028、无凭证负例、快速模式对照、强制停止后重新识别。
- 上述回归均确认 `independentSession=true`，未导入系统账号。随后检查正式包设置页及滚动布局，未观察到目标应用崩溃。

## 兼容边界

小米网页登录适配目前针对超级小爱 8.2.62.3916。厂商私有协议及硬件签名能力不能保证跨版本可用；不将专家模式标记为免 Root。应用保留既有会话、用户配置和识别记录。

## 发布规则

变更以中文 `fix:`、`feat:`、`refactor:`、`perf:`、`chore:` 提交拆分。推送 `v1.4.0` 后由现有 GitHub Actions 构建、签名并发布 APK 和 SHA-256；Release Notes 自动列出上一标签到本次标签的全部提交标题与正文。
